# The Physical World: Interactive Illustrations

Interactive Streamlit illustrations for introductory physics, including
one- and two-dimensional kinematics, projectile motion, and Newton's laws.

## Deploy with Streamlit Community Cloud

Push this folder to a GitHub repository. In Streamlit Community Cloud, create
a new app, select that repository and branch, and set the main file path to
`app.py`. Dependencies are installed from `requirements.txt`.
